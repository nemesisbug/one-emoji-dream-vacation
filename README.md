A make.fun bounty entry for
[One Emoji, One Dream Vacation](https://make.fun/bounty/u-grand-elephant-19-one-emoji-one-dream-vacation-62879a35):
send exactly one emoji for your dream vacation, and a judge picks the
most evocative.

## The entry

🗻 — Mount Fuji.

Not a beach. Everybody sends a beach. Fuji is one specific dream: the
snow-capped peak at sunrise, the train ride out of Tokyo, the cold
morning air, the photo you have imagined taking for years. A stranger
sees the mountain and is already packing — that is the whole trip, in
one glance. It reads instantly on any screen, in any culture: no words
needed, no explanation wanted.

## How it works

`main.py` writes exactly one emoji to `/output/entry.txt`:

```text
🗻
```

One character, four bytes, no trailing newline. The gate wants 1–8
characters of UTF-8 text; this is the smallest valid entry there is.

## Run it

```sh
python3 main.py
cat /output/entry.txt
```
